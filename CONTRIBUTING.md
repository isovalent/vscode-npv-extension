# How to Contribute

Thanks for your interest in contributing to the Network Policy Visualizer
extension for Visual Studio Code! Here are a few general guidelines on reporting
bugs and suggesting changes that we ask you to review.

## Reporting Issues

Before reporting a new issue, please ensure that the issue was not already
reported or fixed by searching through our
[issues list](https://github.com/isovalent/vscode-npv-extension/issues).

When creating a new issue, please be sure to include a **title and clear
description**, as much relevant information as possible, and in particular:

- the extension version, shown in the Extensions view;
- the VS Code version, from **Help: About**;
- a policy that reproduces the problem, with any sensitive names or addresses
  removed;
- any errors from **Developer: Open Webview Developer Tools**, if the panel
  stays empty or shows an error.

Isovalent and Cisco customers can also report problems and give product feedback
through their usual support channel.

**If you discover a security bug, please do not report it through GitHub issues.
Instead, please see the security procedures in [SECURITY.md](SECURITY.md).**

## Suggesting Changes

The extension is developed in a private Isovalent repository and published from
there, so this repository does not accept pull requests. To suggest a feature or
a fix, open an issue describing the problem it solves.

Thanks again for your interest in Network Policy Visualizer!
